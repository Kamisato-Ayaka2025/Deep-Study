# ADR-009 — 实验仅生成材料，删除本地执行

- 日期：2026-10-17
- 状态：accepted（用户明确授权需求变更；实现及人工验收另计）
- 取代：ADR-006 关于当前产品必须通过 PSEC 才开放实验的范围；不撤销旧证据。
- 依据：用户要求“将本地评测功能全部砍掉”，LLM 生成源文件、测试文件和测评方案，用户自行检测，不依赖 MinGW/G++ 等。

## 决策

删除编译/运行/Judge/内部参考解验证；归档旧 Runner 和对应测试，不作为新产品测试通过数。保留历史 246 执行/242通过/4失败。
LLM 接收简单 C 和安全约束，宿主进行结构、限额、路径和明显危险内容检查；无法证明代码绝对安全或正确，界面明确未经实跑。
应用不为用户启动任何生成文件。生成及导出不会自动完成课程。用户显式确认自行测评后记录 userAttested，解锁后继。
每课独立不可变材料包，连续实验说明前课衔接；外部代码不自动采集，取消外部工作区自动继承及破坏性恢复。重新导出原始包作为恢复方式。
无外部隔离软件、驱动或分区操作；不删除现有用户环境/VHD。理论、凭据、来源及模型外发保护保留。

## 实施默认与取舍

完成记录可信度是用户自述，而非机器验证。2026-10-17人工反馈修订：模型区分题目/工程，题目提供外部编译的断言测试源码，工程提供操作与预期。不提供自动执行脚本；软件仍不执行。README统一Markdown。只支持简单 C，不因删除编译器而扩展语言范围。已有计划 msvc/mingw 字段仅作兼容数据，新计划使用 portable-c；冻结旧计划 hash 不重写。软件不要求安装任一工具链。
原始文件保存在应用数据库；导出为新 ZIP，安全条目名且不覆盖已有文件，用户自行解压编辑。整学科删除不追踪已导出的包。

## 验收

结构负例、危险 API/脚本拒绝、路径安全、授权/有限重试/取消、持久化、导出、用户确认与前置解锁；真实 DeepSeek 合成材料及实际桌面检查。禁止用这些测试宣称外部代码执行安全。P6/P7 独立后续工作不随本 ADR 自动完成。

## 2026-10-18范围补充

用户签收当前P5，并批准R-CPP-ACCEPT-01作为第一版最终核验待办：C++单文件算法题属于exercise；C++算法竞赛课程每个算法至少一道实验题。此决定扩展未来第一版语言范围，当前简单C实现不据此冒称已有C++支持。所有不执行生成文件的边界继续有效。
