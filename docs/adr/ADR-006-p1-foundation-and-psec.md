# ADR-006：P1基础验收与PSEC真实代码开放门禁拆分

- 日期：2026-10-16
- 状态：用户已决定；阶段自动与人工验收分别记录。
- 取代范围：ADR-005关于所有安全项同时阻塞P1的阶段安排，以及内存限制的必过地位；严格读取、首期禁网和IPv6排除决定保持。

P1验收当前登记的固定合成夹具下的双工具链、隔离基础、IPC、停止/退出、现有宿主文件入口和模型外发应用门禁。其自动检查通过后可交P1基础人工验收，不代表REQ-034全部完成，不得开放真实代码。

PSEC为真实用户代码和模型参考解执行前的独立强制门禁。磁盘硬容量、完整文件/通信/生命周期攻击、真实宿主文件处理与实际模型外发集成保留必过；详见docs/acceptance/PSEC.md。保留原失败卷测试，用Gate=PSEC分类，禁止Skip、删用例或改断言。P1报告必须记录选择器、阶段外检查、PSEC blocked和realCodeEnabled=false。

用户同时决定暂不考虑内存限制，成品后再决定是否要求。登记R-MEM-01，退出P1/PSEC/首期成品强制验收范围；已有实现与回归作为现状保留，不主动拆除，不新增内存专项工作。它不提供全面内存耗尽保障，可能影响宿主响应和其他应用；其余资源和隔离要求不随之放宽。

P2–P4及无真实执行入口的产品开发可以推进；P5真实执行和完整实验产品发布必须等待PSEC。仅理论预览版可以在明确缺失实验功能时交付。Agent不得替代用户签署P1或PSEC人工验收。
