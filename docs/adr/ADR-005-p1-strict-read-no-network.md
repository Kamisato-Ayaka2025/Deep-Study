# ADR-005：严格读取隔离与首期禁网

- 日期：2026-10-15
- 状态：用户已决定；实现及完整验收待完成。

用户本轮明确接受：首期实验禁网、严格拒绝无关文件读取、继续验证 PSEC；资源限制、宿主文件处理和模型外发边界为开放真实代码执行前的必过条件。当前网络不支持 IPv6，用户明确要求不探索 IPv6 情况。

本决定取代 `docs/assessment/P1-isolation-boundary-decision.md` 中 B1/AAP/ARAP 豁免及“不实施 PSEC”的建议。原评估保留作历史输入，不再作为当前需求决策。网络禁用是实际范围变更，不是把原“本机通信可用”解释成已不存在。

PSEC 候选删除网络 capability 和 loopback allow，保留默认拒绝；只读必要依赖、读写独立运行副本、其他磁盘路径拒绝。不把工具链或任意包级授权等同于敏感数据豁免。所需系统能力缺失时拒绝启动；当前仅有本机 Home 的证据，不能承诺其他版本已验证。

IPv6 不在本机此次测试范围，报告标为明确排除/未验证，不算测试通过。策略仍须默认拒绝，不配置 IPv6 放行规则。停止主动 IPv6探测，包括映射地址探测；不将本机无路由作为安全证明。

真实代码开放前须验证内存/进程数/CPU/输出/磁盘容量限制、宿主读取及回写清理的链接和竞争防护，以及模型外发授权与来源边界。默认不自动发送运行输出或程序修改的文件；展示给用户选择发送时仍须经过外发授权。长度上限是资源控制，不能防止秘密外泄。用户/模型代码不能写自己的通过结论供宿主采信。

本 ADR 不宣称 P1 已通过；生产后端切换、双工具链全门禁与人工验收仍需分别记录。仅固定合成探针可用于验证候选。
