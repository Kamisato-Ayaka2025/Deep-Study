# P10 人工验收清单

2026-10-20用户整体签收，P10 accepted，见P10-signoff.md。以下保留验收操作清单；正式版1.3.0，历史候选演示仍可使用。

可运行`artifacts/releases/1.3.0-rc.3/start-manual.cmd`打开已备好的独立合成演示库，从课程图进入n2/n3/n4/n6/new；已有5节材料，作答进度为空，不需配置API或点击生成。该演示不访问实际学习库。

使用独立测试数据目录；合成课程进度仅为验证数据。升级前退出应用并备份整个数据目录，首次升级learning.db到v8会保存verified备份。回退1.2.0须恢复对应旧库，不让旧程序打开v8。软件不执行课件代码。

1. **H-P10-1 代码可读与复制**：查看独立代码、例题围栏和题干代码；关键字、注释、字符串和数字颜色可区分。选取并复制含缩进、中文和尖括号的代码到文本编辑器，核对原文；未知语言仍显示完整文字。
2. **H-P10-2 数学展示**：查看行内上下标、独立公式、矩阵与连续推导，宽公式可局部横向滚动。裸x_1保持文字。长公式独立成行是生成指导，模型排版不佳不因此拒绝课件；此项确认可读性，不承诺所有未来模型输出完全遵从。
3. **H-P10-3 稳定选项与解析**：新题四项；旧2/3/4/更多项保留数量。记录当前字母顺序，错误提交后重试、答对后刷新、切课再返回及关闭重开均保持顺序。正确答案文字与当前字母一致；旧解析原编号对照清楚，矩阵A等普通文字未被替换。
4. **H-P10-4 升级与学习状态**：旧课/完成记录可读，升级不会重生成课件。新课和历史版本的原ID判分、已答对累计规则保留；未答对时不显示答案或编号映射。遇到排列记录损坏应提示恢复，不静默重新排列。

自动验证使用固定夹具和合成学习库；没有把模拟生成算真实模型质量证据。P10不重复P8/P9收费基线，不新增OCR。代码颜色、公式效果和答题体验已获用户整体签收；不补造逐项人工日志。

正式版入口：先退出旧版，运行artifacts/releases/1.3.0/start-current-data.cmd可继续目前真实课程。该入口与独立合成演示入口不同；原rc.1/manual-data现有真实课程，不得清空。

5. **H-P10-5 自由学习**：所有前置课未完成时直接选择后续理论/实验，生成按钮可用；理论可作答并保存位置，实验可在明确自测声明后确认。只有当前课进度改变，前置课不会被自动标记完成；重新打开软件检查记录保持，历史文章仍只读。
