# Deep Study 1.4.0-rc.1 人工体验清单

本轮按UI-Recommand.md完成需求与计划后自动推进。人工审美反馈与正式签收仍由用户完成；自动证据见归档根HANDOFF及报告，包内文字可能为验证前冻结状态。

1. 主对话：填写目标和可选细节，展开联网/导入；退出重启仍保留输入。课程与设置切页不丢草稿。
2. 资料：导入PDF/.c/.cpp或目录，与联网资料共同形成发送内容；核对后发送，拒绝则清空预览但保留输入。教材全书本地索引，扫描页可分批识别，每批最多20页并单独授权。
3. 计划：补充信息在页内展开，通过同一“形成发送内容→发送”流程重拟；确认计划后课程进入“我的课程”，主对话变为新草稿，旧资料不自动带入。
4. 课程：卡片显示完成/总课数，低于10%红色，10%至未满100%橙色，完成绿色。垃圾桶弹出确认，取消不删。进入后左上箭头返回列表。
5. 路线：第一课在上方，节点不重叠、顺序箭头不交叉；此图表示学习顺序，真实前置关系在详情显示。单击看详情，双击（或Enter）打开学习。
6. 课文：当前课程标题；无文显示“点击自动生成课文”，有文显示“重新生成课文”。重生成二次确认，失败/取消保留原文，成功后旧版仍可在历史阅读。右侧答疑保留。
7. 设置：模型与密钥保存；检测连接仅发送“你是什么模型？”，回复显示在状态区。检测会产生实际API用量，未保存输入不会代替已保存配置。
8. 视觉：蓝白、留白、按钮对比度、最小960×700与最大化；请反馈具体偏好的布局、颜色及信息密度。

旧1.3.1及真实库原地保留。本轮不自动操作真实库，不执行生成代码。第一次浏览可使用start-manual.cmd中的独立合成演示库；继续实际课程需退出旧程序后由用户启动start-current-data.cmd，早期课程使用start-earlier-data.cmd。不要清空任何manual-data。
