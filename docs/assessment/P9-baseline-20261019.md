# P9离线基线和来源核验

基线8db5301 / P8 rc.2。此次冻结对照规则，不声称产品已达门槛。

旧装配：普通网页理论课发送全部绑定来源；教材按页/标题4000字符切，检索每节种子、邻接及剩余候选持续填预算。P9对照固定同一原文，不删难例，比较正文+相同指令/输出预留的估算总输入；真实API usage另列。

固定集使用自有合成标注，至少12关键单元：定义、定理、证明、跨页证明、例题、解答、跨页解答、公式、表格、代码、超长续接、后章定义。Markdown/文字PDF/缓存OCR各自验证全字符覆盖与定位，缺失OCR页不算读取。来源负例每目标含正文/简介/目录/广告/不相关，另有提示词注入和相似域名。标注不依赖模型自评分。

来源调查（2026-10-19）：

- [OI关于页](https://oi-wiki.org/intro/about/)链接维护仓库，社区维护；[二分正文](https://oi-wiki.org/basic/binary/)有实际过程/性质/实现，区别于首页。
- [OI镜像列表](https://oi-wiki.org/intro/mirrors/)声明主站海外部署，oi.wiki由Menci维护、Azure+阿里云CDN。[镜像二分](https://oi.wiki/basic/binary/)和[C++正文](https://oi.wiki/lang/basic/)可由当前工具读取。大陆直连仅为优先目标，尚无大陆终端实测，不标verified-mainland。
- [中文线代专题](https://oi-wiki.org/math/linear-algebra/)为发现目录，须继续核验子页；它侧重算法数学，不等同完整大学教材。
- [MIT18.06SC](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/ax-b-and-the-four-subspaces/elimination-with-matrices/)主要为课程活动入口，不能把它当完整消元正文。[LearnCpp教程](https://www.learncpp.com/cpp-tutorial/variable-assignment-and-initialization/)有正文，但用户要求国内可达优先，两者不作为默认推荐。
- 国内高校/出版社搜索返回不少图书介绍、PDF、登录教学平台；不以.edu.cn或简介冒充可引用正文，不绕过访问限制。

预算和版本冻结见TURN-014；固定集100%和30%门槛只适用于有限标注集。后续真实内容/国内用户体验单列人工清单，不能由上述联网工具代替。

## 离线实测（TURN-014）

固定普通网页混合集：P8总输入25050字符/保守估算50100 tokens，P9为5029字符/10058估算tokens，减少79.92%；两课分别命中二分和前缀和必要正文。固定长教材混合集：P8原4000切块填预算为105000字符/210000估算tokens，P9为5064字符/10128估算tokens，减少95.18%，3/3必要定义/例题/解答保留。两臂都加相同5000字符指令与输出预留，用于固定对照，不冒充真实模型token计费；真实完整请求仍由M07校验。

长教材首个未声明任何结束边界的解答+18万字续文触发完整证据超预算，原失败保留final-offline/p9.trx。没有猜测它在哪里结束：保留为AmbiguousUnboundedSolution负例，要求拒绝装配；另增明确水平分隔线的混合正文正例，验证可辨结构下的输入减少，不把模糊边界样例计作优化成功。固定12关键语义单元全正文覆盖/证据回查与跨页证明续接测试同时保持。
