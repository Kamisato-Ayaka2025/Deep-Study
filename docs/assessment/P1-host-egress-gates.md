# P1 宿主文件与模型外发门禁（2026-10-16）

本轮范围是当前固定合成夹具Runner及宿主模型接口。以下为代码和本机负例证据，不是“任何输入都绝对安全”的承诺，也不是P1最终验收。真实代码/真实DeepSeek仍关闭。

## 宿主文件

| 路径 | 强制行为 | 证据/边界 |
|---|---|---|
| 固定夹具读入、执行后产物读取 | 逐层打开规范本地盘符目录，禁止写/删除共享，拒绝任意层重解析点；同一已核验文件句柄读取，拒绝硬链接，最多65536字符 | SafeRunFilesTests；盘符大小写可不同；短路径、ADS、UNC、设备命名空间、尾点/空格拒绝 |
| 源码复制及stdout/stderr宿主创建 | 安全固定目录内直接子文件、CreateNew、禁止覆盖旧文件/链接；写入使用已打开句柄 | 输出预植硬链接及目标已存在负例，原哨兵不变 |
| 并发替换 | 目录逐层保留FILE_LIST_DIRECTORY句柄，FILE_SHARE_READ；文件读句柄不共享写/删除 | 父目录和work改名均失败；原地写junction失败；释放后改名正对照成功 |
| 运行产物回写原项目/递归清理 | 当前没有这些产品入口；隔离测试不再删除预植escape名称 | 不声称未来导出、覆盖写回、递归删除已通过；新增入口前必须有独立安全设计/负例 |

第一次并发测试发现desiredAccess=0虽无共享删除仍可改名，测试明确失败。修复为FILE_LIST_DIRECTORY并移除写共享后才通过；原失败TRX保留。宿主目录需要列目录权限才能固定句柄，权限不足则拒绝操作。卷目录挂载点也是reparse，本API拒绝；未来使用核验过的专用盘符根接入，不能放宽到任意挂载点。

## 模型外发

ModelEgress是可信宿主应用边界。IModelProvider现在只接收Application内部构造的ApprovedModelRequest。来源ID、修订、类型、全文、提供方目标和模型在预览时冻结，没有延迟文件读取，调用者替换原始集合不会改变待发送文本。

| 条件 | 结果 |
|---|---|
| 未授权、拒绝/撤销、跨请求快照或跨门禁实例授权 | 不调用提供方 |
| 运行输出、程序修改文件、凭据来源 | 不可批准，不调用提供方；不能因长度小或在work内而提升可信度 |
| Each | 锁内先消耗后调用；并发12次仅一次到达提供方；失败后也不自动重用授权 |
| Once | 仅重复使用同一已告知快照；来源修订/内容/模型或目标改变须重新授权 |
| 发送前取消 | 不调用提供方；已分发的字节不能靠撤销追回 |
| P0固定自检 | 无调用者可控内容，仅local:deterministic-fake；外部目标拒绝 |

捕获提供方是纯内存测试，无HTTP请求。检查“实际进入提供方的内容”和“拒绝时调用次数为零”，不是只检查提示文案。提供方及宿主应用属于可信代码；此机制不是抵御同进程恶意插件的安全沙箱。

### 未来接入不得绕过的条件

- 真实资料导入必须由可信宿主确立来源；不能接收Runner/模型给出的OriginalMaterial标签或通过重新包装运行输出改变来源。用户编辑文本也可能含秘密，来源门禁不是语义秘密检测器。
- 授权UI必须显示该不可变预览的目的地、模型、来源及内容范围；未实现的UI不能由程序自行批准。当前桌面只接固定Fake自检，未接通Prepare/Approve真实业务。
- 一次授权目前仅支持同一快照的范围。课程级增量授权需另行设计明确范围、撤销与新增资料提示，不能以设置中的Once值自动生成授权。
- 真实DeepSeek连接器必须只序列化已批准载荷，鉴权密钥不得加入内容；还须验证目标固定、重定向/重试、日志脱敏、取消和实际HTTP发送体。此部分仍是未来模型接入门禁，不声称本轮已联网验证。
