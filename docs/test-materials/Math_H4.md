# 纯数学：集合、关系与函数（H4合成测试资料）
这是Study Harness H4原创合成教学资料。学习目标是理解有限集合、集合运算、二元关系及函数的定义，能够用小例子解释并判断。假定零基础，预计四至六堂理论课，每堂30至60分钟，按用户每周时间排周计划。本方向是纯数学，不包含编程、上机实验或实验工具链；例题推导属于理论课活动。
## 集合与运算
集合由确定且互不重复的元素组成，元素顺序不影响集合。设A={1,2}，B={2,3}，则A并B={1,2,3}，A交B={2}，A减B={1}。空集没有元素，是每个集合的子集。目标：区分属于与包含，计算有限集合的并、交、差；前置：无。
## 笛卡尔积与二元关系
A与B的笛卡尔积由所有有序对(a,b)组成，其中a属于A、b属于B。A上的二元关系是A乘A的子集。关系自反表示每个a都与自身相关，对称表示a与b相关时b也与a相关，传递表示a与b、b与c相关时a与c也相关。目标：枚举两个小集合的笛卡尔积，用有限关系检验三种性质；前置：集合。
## 函数
从A到B的函数给A中每个元素恰好指定B中一个值。单射要求不同输入有不同输出；满射要求B中每个元素都被某个输入取到；双射同时满足二者。例如A={1,2}、B={a,b}，映射1到a、2到b是双射；两者都到a是函数但既非单射也非满射。目标：区分关系与函数，判断单射、满射和双射；前置：集合与关系。
