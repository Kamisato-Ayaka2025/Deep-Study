# P3简单C测试资料使用说明

此目录的C_Basics_P3.md是原创合成资料，可用于模型外发测试。此说明不是课程资料，不必导入。

## H1准备步骤

1. 在“资料与模型”页点击“导入 PDF / Markdown”，选择E:\Code\Test_For_StudyHarness\C_Basics_P3.md。仅把文件放进目录不等于已导入；已有资料库不会自动监听新增文件。
2. 查看提取结果；如果有检索框，可清空检索条件或用“简单C语言”检索。依次选择资料块，点击“保留所选版本引用 / 加入外发范围”。建议选入范围说明、变量、循环、函数、独立实验五块；测试连续项目时再选连续项目块。
3. 从外发范围移除不相关的Test1资料，避免模型要求解释不适用的优先素材。不要删除原文件。确认引用栏含所需C语言资料。
4. 回到主对话，填写学习需求、基础、目标、每周时间和范围，点击保存草稿。已有草稿也必须重新保存，才会记录新选引用。
5. 点击“预览计划外发”，核对提示与C资料内容，再同意拟定。预览失败不消耗模型API用量；同意发送后的真实生成会消耗用量。

## 可用的H1输入

- 学习需求：零基础学习简单C语言，按变量、条件、循环、函数安排短课，最后完成独立的小整数求和实验。使用已选资料。
- 基础：零基础。
- 目标：能解释变量和循环，并使用函数计算0到100范围内整数n对应的1到n之和。
- 每周分钟：120。
- 实践范围：选择简单C对应项（SimpleC）。

这些输入供测试使用，课数由模型按时间和前置关系安排。核对已填写字段被保留、实验存在、来源正确、单课时长不超过每周预算；没有解决的澄清应先调整，不强行确认。

## INSUFFICIENT_SOURCES的含义

当前预览优先使用草稿中保存的引用；没有引用时在当前库中检索。检索是整段请求的文本包含匹配，不是语义检索，长请求即使面对相关资料也可能无命中。因此本轮测试明确选入资料并重新保存草稿。无可用引用时返回INSUFFICIENT_SOURCES符合REQ-006资料不足需补充的要求；它不表示API密钥无效，也不是模型判断了内容质量。已选但无法读取的来源则返回SOURCE_UNAVAILABLE。

当前仍是P3人工验收，完整学习、运行和评分未交付；H1成功不代表其他H项签收。核心测试可围绕C语言，H4中的数学/范围外输入保留为规则边界负例。
