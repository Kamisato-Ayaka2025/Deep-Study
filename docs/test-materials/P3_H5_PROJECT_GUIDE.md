1. 从 `scripts/manual-p3.cmd` 打开工作台。设置中的 API Key 留空表示复用已保存密钥，无需重新输入。
2. 进入“资料与模型”，先确认资料库目录，再点击“导入 C 项目目录”，选择上述项目目录。
3. 检查导入结果，点击“以本次导入替换读取范围”。这会替换引用栏，不会把资料库其他项目一并加入。
