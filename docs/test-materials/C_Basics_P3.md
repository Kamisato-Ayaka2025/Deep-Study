# 简单C语言学习：P3测试资料
本文是为 Study Harness 人工验收编写的原创合成教学资料，不是外部教材摘录。对象是零基础学习者；目标是理解变量、条件、循环和函数，能够写出处理固定小整数的简单程序。建议按每周120分钟规划短课，允许拆分课次；只使用标准C基础语法与控制台输出。P3仅验收计划和课程图，不生成课程正文或运行代码；实验描述为后续阶段的设计素材。无文件读写、网络、动态内存、指针教学、图形界面或外部库要求。
## 简单C语言：变量与表达式
C程序从main函数开始执行；使用标准库输出时包含stdio.h。入门采用int main(void)，正常结束return 0。先学习int变量的声明、初始化、赋值和整数表达式；例如int a = 2; int b = 3; int sum = a + b;得到sum为5。printf("%d\n", sum)按十进制打印int并换行。整数除法5 / 2结果是2；余数5 % 2为1。变量应在读取前初始化。练习只选结果可表示的小整数，不假设有符号溢出会安全回绕。学习目标：解释每行代码和变量值变化，区分赋值与相等比较，预测简单表达式结果。前置：无。
## 简单C语言：条件与循环
if根据条件真假选择分支；==判断相等，=用于赋值。用if (n % 2 == 0)判断小整数是否为偶数。for循环包括初始化、继续条件与迭代步骤；int sum = 0; for (int i = 1; i <= n; i++) { sum += i; }在n非负且足够小时求1到n之和，n为0时循环不执行，sum仍为0。重点解释i <= n与i < n的边界差异。学习目标：手工跟踪n为0、1、5时的i和sum，结果分别为0、1、15；说明循环为何结束。前置：变量、赋值、算术和比较。
## 简单C语言：函数与分解
函数封装一个小任务，通过参数接收值，通过return返回结果。例：int sum_to(int n) { int sum = 0; for (int i = 1; i <= n; i++) { sum += i; } return sum; }。先定义sum_to再从main调用，可避免在此阶段引入额外声明规则。约定输入n为0到100的整数，此范围的求和结果适合标准C至少保证的int范围；范围外不属于该练习的有效输入。学习目标：区分参数与返回值，把循环提取成函数，并对0、1、5、100分别得到0、1、15、5050。前置：变量、条件和循环。
## 简单C语言：独立实验素材
独立实验“小整数求和”：从空白main.c开始，使用stdio.h、main、int变量、for循环和sum_to函数，实现对固定n的求和并打印结果；不要求scanf或处理交互输入。工具链可选MSVC（msvc）或MinGW GCC（mingw），使用标准C；同一实验固定选定工具链。最小版本先在main内完成n为5的求和，再整理为sum_to函数。预期输出一行15。检查有效边界n为0、1、100分别输出0、1、5050。验收证据是源代码、输出与对循环边界的解释；仅生成计划不能视为实验完成。实验模式为独立，不继承其他实验文件。前置课覆盖变量、循环、函数；预计45至60分钟，可按学习节奏拆分。后续PSEC解除前不在Study Harness内执行这些代码。

需要测试连续实验计划时，可选择“小整数统计器”项目，输入使用代码中固定的0到100整数，不使用外部文件。建议四个递进实验：一、打印固定整数并判断奇偶；二、在前课当前代码上增加1到n求和；三、在前课当前代码上把判断和求和整理为函数；四、在前课当前代码上加入0、1、5、100的固定测试调用并逐项核对结果。第一实验为独立起点，其余明确标注连续模式、直接继承的前一实验以及相同工具链；每次保留前课功能。计划需安排对应理论前置，每个实验约30至60分钟。该方案与独立求和实验是可选方案，无需全部编入一份计划；由用户在确认计划前选择。本资料只描述继承意图，不代表当前已实现快照、执行或学习评分。
