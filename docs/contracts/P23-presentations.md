# P23 PPT/PPTX资料契约

对应REQ-088 / TURN-20261028-012。

- SourceKind新增presentation；数据库格式不变，page-N与原幻灯片顺序一致，含隐藏页。SourceRef保留原文件名、页号与正文hash。页面标题进入目录；标题不作为正文缺失的替代。
- PPTX直接读Open XML包，不按slide文件名字典序排序；表格行列和讲者备注保留。XML禁用DTD与外部解析，外部关系不抓取。每文件512MiB、最多2000页、解压总量1GiB、XML16MiB、每页文字65536字符；文本资料既有32MiB限制保持。
- 图形/图片/连接线/图表/公式及母版背景图片进入远端视觉通道。纯文字/原生表格直接就绪；图示页原生文本先入库，未完成视觉识别不冒称整页就绪。
- 已安装Microsoft PowerPoint负责旧PPT转PPTX、静态页PNG导出；只打开应用临时副本，强制禁宏，不启动幻灯片放映，不运行嵌入对象。PPTX渲染副本移除外部关系。渲染每批最多20页，远端最多4并发；COM调用本身不可强制取消，当前打开/导出返回后响应取消，不继续派发。
- 原始文件只读，临时副本完成后清除。保留已有用户PowerPoint窗口；恢复原AutomationSecurity/DisplayAlerts。没有打开文稿时结束本轮自动化实例。
- presentation-v1标记提取身份，同源重复导入与已识别页复用缓存。视觉结果与原生文字/备注合并，不覆盖丢失；不可变旧版本引用保留。无需数据迁移。
- 规划以主题而非页数决定课程，coverage仍映射实际page-N。单课按目标选取命中页及绑定范围内相邻同标题页，停止于其他主题，受现有字符预算约束；不得靠填满剩余预算发送整个课件。
- 不增加真实模型派发来验证导入器。本轮远端链路用可辨识假Provider测试，真实远端理解/生成效果由用户后续验收；本地导入与渲染耗时分别记录。

PowerPoint接口依据：[Presentations.Open](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.presentations.open)；只读及无窗口参数用于打开私有副本。
