# P7联网学习实施交接 — R-WEB-LEARN-01

状态：实现开发中（TURN-20261019-001），新增接口已接通，完整验收未完成。本文件的验收要求保持，不能以开发证据代替通过。依据：TURN-20261018-008；优先级为P7正式验收必须前置。

## 入口与行为

1. 新用户、空资料库，仅提出“学习C++算法竞赛”，无需提供教材或网址。允许沿用学习基础、时间、目标访谈及默认值；资料缺失本身不能阻止进入搜索。
2. 用户也可指定资料站点或URL，例如OI Wiki。指定来源优先；不足时说明缺口并按授权补充其他来源。
3. 本地优先复用；本地不足时搜索→读取正文→提取知识→保存快照和来源→生成待确认计划。搜索结果摘要不能冒充正文；模型预训练知识不能冒充已取得来源。
4. 计划确认后保持冻结；逐课按需生成。每个确认算法至少一道实验题，理论和题目均可追溯来源。搜索不是自动完成课程或自动执行代码的依据。
5. 重启可复用已保存知识，网页更新/删除不能改写旧课程；资料过时或冲突应显式说明，不静默采用新内容替换旧引用。

## 模块与契约责任

- M01/M02：学习入口、可选指定URL/站点、获取进度、取消、缺口提示及授权；普通用户不需要先手工下载教材。显示实际服务及外发范围，沿用已有授权习惯，不默认把本地正文/代码/学习记录传给搜索服务。
- M03/Infrastructure：搜索与网页读取端口、正文提取、去重与知识版本。持久字段至少含原始URL/最终URL、标题、获取时间、内容摘要或版本、提取知识；失败记录不伪装为可引用正文。抓取原文无需永久保存，提取知识和引用快照须可复用。
- M04/M06/M07：有界检索编排，模型工具只经宿主受控端口调用；先获取资料再绑定快照生成。DeepSeek仍是LLM服务；搜索服务独立建模，不假定chat/completions自带联网。来源不足时不派发声称有来源的生成请求。
- M09/M12：保持材料与来源绑定、导出和删除语义；任何数据变更提供迁移及旧数据回归。Domain不引入IO/网络依赖。明确新增知识与整学科删除/共享库保留关系。

实施时先阅读现有MaterialRetrieval、DeepSeekProvider、知识库和计划授权流程，落地接口、DTO、预算和迁移方案，再写接入与UI。2026-10-19已选用DeepSeek Search/Fetch，复用现有密钥；价格遵循服务商公开规则，调用有界。没有预先批准付费购买、注册账户或上传私有资料，必要时提出具体决策；不能用仅支持URL读取代替真正搜索。

## 获取边界与异常

- 按2026-10-19用户决定，采用DeepSeek服务端抓取边界：宿主校验提交URL，仅连接固定HTTPS API、不跟随API重定向，不直接连接网页；网页DNS/重定向/私网拒绝由DeepSeek承担。不要求宿主取得服务端最终连接证据，不能冒称已验证；网页不能成为本地文件读取通道。
- 限定请求数、正文大小、总字数、超时、重试与取消；明确搜索成本与模型成本，不能无限补搜。具体数值由实施契约及测试冻结。
- 不执行网页脚本/下载的代码，不绕过登录、访问限制或站点规则；仅将经处理的资料进入现有安全渲染。网页中的提示词/工具调用指令不得改变权限、泄露凭据或覆盖系统约束。
- 断网、限流、服务配置缺失、空结果、无正文、损坏页面、来源冲突及用户取消必须可恢复且有清晰提示；不得在重启后自动收费重试或伪造成功。已有本地学习路径仍可使用。

## 2026-10-19实现边界（开发中）

采用官方DeepSeek `/v1/tools/search`、`/v1/tools/fetch`，复用现有DPAPI密钥，无新账户。用户明确点击授权，发出搜索主题（默认学习请求）、可选站点及公开URL；不发送本地正文、代码或学习记录。模型计划仍独立预览授权。

每次1次搜索（5结果）、最多3次抓取、每请求45秒、整体3分钟、响应512KiB、单页正文60000字符；无自动重试。仅HTTPS/443/无用户信息/DNS主机名，拒绝IP及常见本地域名；搜索的HTTP链接只转换为HTTPS，不请求HTTP。指定站点含其子域；按查询词匹配标题排序，去重后抓取。失败不保存摘要或发布计划。

正文切为最多12000字符块，知识库首次保存网页时在同一事务升级user_version 1→2；旧本地数据保持，旧程序拒绝写入v2以免丢失来源元数据。WebSnapshots记录OriginalUrl、FinalUrl（服务未提供时null）、Title、RetrievedAt、ContentHash、Query。原始引用版本/hash不改，重复正文沿用原版本；资料库共享，删除学科不删除网页知识。禁止用旧程序写入新版库，回退需回到升级前备份。

宿主唯一HTTP连接目标为固定DeepSeek HTTPS API且不跟随API重定向；网页DNS/重定向由服务端执行。官方文档说明Fetch安全策略拒绝返回403，但不返回最终URL、DNS/连接证据。2026-10-19用户明确接受此服务端抓取边界，取代原宿主验证网页最终连接要求。WEB-06现在验证固定API目的地、API重定向拒绝、提交URL拒绝、外发授权与内容限制；不将其解释为独立验证了DeepSeek内部实现。 不虚构FinalUrl或本机完成抓取安全验证。

开放联网与指定OI Wiki各有独立22项完整成功证据；最新全门禁仍因后续模型课件不合格失败。来源/题目校验保持，未发布新候选。各次提交、失败与成功范围见TURN-20261019-001，不将分散证据拼接为全门禁通过。
用户界面不展示抓取过程、重定向或FinalUrl缺失，仅显示简短的查找/整理资料状态；后台保留可追溯来源和开发诊断，课程引用照常可核对。用户原话：接受抓取边界，本地什么都不用显示，不需要展示给用户抓取的过程；开发过程中可做小提示说明LLM正在做什么。

理论课输出采用DeepSeek Responses的JSON Schema模式，目的地https://api.deepseek.com/responses，并绑定现有理论Schema。授权预览使用该真实目的地，无静默跨端点回退。来源范围与本地严格验证不变；计划工具循环、实验及普通答疑仍走chat/completions。依据与真实探针见TURN-20261019-001。
