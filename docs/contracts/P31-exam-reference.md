# P31 试卷参照契约

教材与试卷可同时导入；新增导入考题入口，角色属于当前草稿/冻结计划，不更改原文件或共享扫描缓存。现有教材默认保持普通资料。题目分析使用独立提示与缓存身份，记录题号、题型、题干条件、显式分值、考点、必要解题知识与难度估计；无答案不阻塞，推导与原答案分开。复用知识清单结构，不增设严格逐题格式拒收。

课程规划以教材补齐基础，用考题确定重点/题型/难度与练习；单套试卷不代表完整考试范围。按课绑定题目原文和教材，生成简明方法讲解及变式。身份与角色随草稿保存、重启恢复、确认后冻结，旧计划兼容。

开发与验收：1角色贯穿混合队列/会话/冻结快照；2试卷分析与缓存隔离；3规划与课文提示及原题召回；4离线集成、真实PDF本地导入、实际桌面与重启、自检候选。验收需确认两类资料同时保留、角色不串、原题数字/图示不凭空补造、缺答案仍可生成、教材旧流程保持。不新增收费调用，实际模型质量由人工试用确认。

## 2026-10-30 真实反馈修订

考题正文携带来源页/块定位；OCR转录、派生考点摘要、原图/人工核对与模型补充分开。常见边列表冲突只提供局部提示，不能借经典教材记忆裁决本卷；无原图确认时可以条件化分支讲解，其他内容继续生成。不增加输出拒收规则，也不改写扫描缓存。

原题先核对全部条件及允许的范围、差集、组合或例外表示；单一解法失败不能当作原题无解，不以放大地址池等改编替代原题。无法明确的含义局部说明，不编造官方答案。

知识映射以节点身份和教学内容复用。课时、前置关系、页面覆盖等计划修订不使完成映射失效；删除未绑定节点允许保留，目标/教学内容变化或绑定节点消失仍需重新分配。完成映射独立持久化，恢复时检查当前节点和全部知识编号；旧逐批缓存继续读取。
