# P36 / REQ-106 长文本性能

仅减少重复工作，保留全部文本、引用校验、缓存分类和计划功能。旧数据库不迁移，不增加持久缓存或失效策略。

- 旧资料库引用读取用JsonDocument选择节点/版本/正文，避免每次构造整库对象与所有正文字符串；身份、版本、位置和内容哈希仍校验。
- 本地集合引用只读打开chunks，避免每次读取执行建表/迁移事务；拒绝未来数据库版本，原导入迁移入口保持。
- 缓存状态每批次取得来源、排除编号与知识证据编号，集合匹配替代逐来源重复扫描大段知识说明；未分类网页保持未完成。
- 完整发送预览在后台构建，仅一次发布到UI；取消后不发布迟到结果。文本顺序、内容和授权范围保持。

验收：相同880条合成引用数据、三轮计时/分配量及完整返回值哈希比较；全回归、缓存列表桌面/重启、联网规划及生成桌面/重启、单次完整预览通知。性能数据只限定该夹具，不承诺模型网络耗时下降。
