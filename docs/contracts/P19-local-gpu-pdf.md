# 本地GPU PDF扫描

**历史契约：TURN-20261028-008已按用户要求退役本地GPU产品功能，1.8.0-rc.4仅使用远端识别。以下保留原实验范围，不是当前安装或操作说明。**

REQ-084 / TURN-20261028-006。用户授权在当前4060上安装并实测本地识别，效果合适后接入；未授权执行学习生成代码。

## 路由与兼容

1.8.0-rc.3起，本地通道必须人工勾选“启用本地 GPU”，默认关闭且仅本次程序会话有效。关闭时所有待识别页直接走原在线通道；开启时才执行以下本地优先策略。扫描期间不能切换，取消后可重新选择。切换不使已有结果失效。

原生纯文字仍直接提取。待识别页先经过本地PP-StructureV3：文字、公式和矩形表格在结构及文本覆盖检查通过后逐页保存；图示语义、复杂表格、低置信度或未覆盖文本交回原有远端流程。模型置信度和结构检查不等于内容正确性证明，原来的未验证/需复核标记保持。图片内容及关系通过原通道转写，未新增独立图片导出。

实测PDF放大页图产生伪字符后，加入一次有界补识别：仅低置信度/未覆盖文本且长边超过1800时，以Lanczos缩至长边1800，继续使用同一检查。失败仍走远端，不降低置信度门槛、不从答案拼接输出。公式使用几何位置对应的专用公式识别结果，避免上游便利Markdown合并重复OCR字符。

本地成功页不读取远端能力或发送付费请求。远端仍使用既有用户授权、凭据、上限及最多4页并发。取消停止本地子进程，已完成页提交，恢复只处理未完成页。原始PDF、冻结引用、历史OCR结果不改。

## 当前机器运行环境

独立解释器`.tools/pdf-gpu/Scripts/python.exe`，模型`.tools/pdf-models/official_models`。Paddle GPU 3.2.2（CUDA12.6）、PaddleOCR 3.3.2、PaddleX 3.3.13，Windows Python3.12。使用PP-OCRv5、PP-FormulaNet_plus-M和PP-StructureV3表格/布局模型。固定det阈值0.4、unclip2.0、边长1280、识别batch8。

候选`app/LocalOcr/runtime.json`记录当前机器解释器和缓存绝对路径；不包含密钥。工作进程仅执行安装目录自带worker.py，以标准输入接收有hash的PNG，不执行PDF路径或内容。扫描前要求所有模型缓存就绪；未安装、启动失败或GPU不足时继续原远端流程。退出程序释放工作进程；首次加载有额外延迟。

运行环境未塞入便携ZIP。移动程序到另一台机器时需另行安装对应GPU依赖、下载模型并更新runtime.json。当前机器保留上述.tools目录即可。依赖安装使用官方Paddle Windows cu126源；完整安装版本可查P19证据中的runtime-packages.json。

## 证据边界

测试材料为四张已知答案合成页及其PDF；未读取用户教材或课程库，未发生真实付费OCR。原始模型输出、调参前失败、应用集成失败均保留。不能把四页检查称为500页教材准确率或整本扫描耗时测试。
