# P3 course graph — WP-P3-001

## 范围与所有权

M05 的纯领域基础，关联 REQ-014/015、REQ-005/016 的生成资格部分及 T01/T02/T03。
本轮没有新增 wire DTO、模型 Schema、数据库或 UI；类型仅供进程内可信宿主使用。
Domain 不引用 Contracts、存储、UI、网络或进程。后续模型计划 DTO 必须单独执行 Schema、
引用子集、学科范围、实验素材、周安排校验，再映射进入本图；本图有效不代表完整计划有效。

## 输入与不变量

- `CourseDefinition`：非空 UUID、唯一非负显示顺序、Theory/Lab、非空标题和目标、正数单课分钟、直接前置 ID。
- `CourseGraph.Create`：图非空，拒绝重复节点/顺序/边、自依赖、跨图或缺失节点、环（含孤立循环分量）。
- 显示顺序不要求是拓扑序。层号由宿主计算：根为0，其余为1+最大前置层号。
- 输入集合深度复制到只读视图，调用者后续修改原数组不能改变已校验图；返回层号只读。
- 非法输入抛 `ArgumentException`（null 参数为其子类）；后续 Application 应转换为 VALIDATION_ERROR 或 INVALID_MODEL_OUTPUT，不能直接将异常展示为模型文本。

## 资格投影

`GetAvailability(nodeId, completed, facts)` 只计算 Plan §4.2 的资格，不产生生成、作答、完成或 Runner 副作用。
`completed` 必须由宿主读取当前学科的 Completion；facts 必须由宿主读取确认、生命周期、正文、活动任务、参考验证状态。
模型、自述掌握、UI 标志不能提供这些权威事实。未知节点拒绝。

读取仅依赖已发布正文；生成依赖确认、全部直接前置完成、学科 active、无正文且无活动任务。
作答/实验依赖正文、全部直接前置完成及 active，并分别限制课型；实验另需参考验证通过。
这只是领域资格，`CanStartLab` **不是执行授权**：Application/Runner 仍必须通过独立 PSEC 门禁。
本轮没有接入任何执行入口。PSEC blocked、真实用户/模型代码关闭保持。
