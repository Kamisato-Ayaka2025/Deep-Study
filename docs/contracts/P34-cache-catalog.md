# P34 设置中的资料缓存目录

REQ-104；TURN-20261030-010。

- 设置“数据位置”下方新增默认折叠的“资料缓存”，列出当前数据目录所登记资料库的资料名称及状态；同名资料可悬停查看来源路径。
- 每页8份，上一页、下一页、页码和刷新；不使用资料列表内部滚动。重新展开、重新进入已展开的设置页及刷新均读取当前记录并回到第一页。
- “已导入”：已有本地导入记录；不意味着扫描或知识整理已经全部完成。
- “已整理知识点 · 缓存完成”：当前版本各目录项均为textReady/ocrReady，且全部正文引用均存在于已保存知识批次。仅部分批次、未识别页或旧正文版本不能达成完成状态。此状态是本地整理结果已保存，不表示模型知识内容绝对正确，也不要求完成课程编排/知识分配。
- 兼容既有book-knowledge.db，不新增完成标志、不迁移用户数据；没有知识提取结果的普通文本/网页只显示已导入。历史正文保留，但清单按当前资料版本显示，不逐版重复列出。
- 查询只读并在后台执行；读取名称元数据，当前页才核对正文引用，不读取原教材正文或执行外发。外部资料库不可访问时明确披露列表可能不完整；读取错误不伪装成正常空库。

WP-P34-001：本地只读目录与状态判定。WP-P34-002：设置折叠区与分页。WP-P34-003：回归、实际桌面/重启及独立候选人工交接。
