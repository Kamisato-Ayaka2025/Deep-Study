以模型最终课程编排为准：移除PKNOW004、PWEB001及自动删除无独立知识绑定的末端课。导论、衔接、综合复习不要求独立提取知识点；知识清单提供参考，不据此否决课程。真实引用/映射编号、可保存的数据结构与课程依赖检查保留；不改变广告清理和缓存状态，不改旧冻结计划。此决定覆盖以下历史契约中相冲突的规则。

# P35 联网资料知识整理与缓存同步

REQ-105；TURN-20261030-011。用户授权实现至人工验收，未授权本轮新增收费实测或正式发布。

## 工作范围

WP-P35-001：普通网页接入资料集合、分批知识提取、规划与缓存；统一初次/按课获取正文清理。
WP-P35-002：站点后续取得正文在课文生成前整理、授权展示及复用；网页非教学/未分类内容处理。
WP-P35-003：逐篇缓存显示、离线回归、实际桌面/重启与独立候选。

## 来源与兼容

- 普通已保存网页投影为web集合，沿用knowledge.db中的原引用和内容，不迁移或重写旧记录。标题/站点/当前正文引用可用于规划和显示。
- OI Wiki保留全站目录及按课取得模式；只有取得的正文参与首次知识整理。未取得条目不是已读正文，首次生成相应课程时获取其正文并进行网页知识整理。
- 保留老计划/hash/历史课文。既有冻结来源范围继续约束可用正文，不借整理自动扩大到未授权网页或全站。
- 初次搜索的既有搜索/抓取次数、凭据/外发边界和站点获取预算不扩大。

## 清理与知识整理

- 初次获取和SaveSiteBody按相同TeachingPages规则清理；原抓取快照保留。排除明确广告、推广、导航/推荐/评论区等页面附属内容，保留教学代码围栏、公式、支撑性链接和Cookie等技术解释。
- web-knowledge-v1逐页按完整正文块分批（目标16000字符、80块，不截断不可分块），模型区分知识points与nonTeachingIds。混合段落仅提取教学内容。
- 网页漏标段落不补为“原文待展开”知识，不进入知识映射及生成课文的正文集合；保留源缓存。未分类正文不算知识整理完成。本地教材既有漏标原文保留规则不改变。
- 规划不允许把已整理但没有教学知识的网页条目included。取课文资料时排除网页非教学/未分类引用；同一混合段落内的非教学语义仍依赖模型遵守提示，不宣称绝对零污染。
- 缓存键包含网页提取协议、模型及精确正文引用；成功批次和收到的原始回复保留，失败/取消可重启复用；正文变化或模型变化不复用不匹配批次。

## 生成授权与计量

- 准备/预览不调用知识模型；展示本课固定网页材料和额外知识整理范围。点击生成沿用现有对本课的明确授权。
- 网页每批首次至多一次提取加一次格式/引用修复，收到回复在解析前保存；完整课文仍沿用原有至多3次派发范围。总耗时沿用课程生成600秒预算，不增加后台自动生成。
- 知识整理仅使用预览中的固定来源；成功提取后课文仅取得其教学正文、知识摘要及本课其他合法资料。只会缩小正文集合，不增加未披露来源。
- 网页提取用量独立记入任务telemetry的web-knowledge阶段；课文用量仍保持原语义。

## 缓存界面

- 每篇已缓存网页按“标题 · 站点”显示，悬停可看URL；每页8项、翻页/刷新沿用P34。
- 站点显示目录条目总数、实际缓存正文篇数、已整理篇数；未取得目录项不冒充缓存文章。
- 当前网页全部正文引用经新网页协议分类后显示“已整理知识点 · 缓存完成”，部分/未分类显示“已导入”；完成表示处理结果已保存，不保证模型知识结论正确。
- 只读缓存目录，不因展开列表触发抓取、知识提取或数据迁移。

## 验收边界

离线模拟搜索/抓取/模型验证完整流程，实际WPF/WebView与重启验证展示。未经本轮真实服务测试的实时网页抓取可用性、真实模型广告识别率和教学质量，不作为自动通过结论。用户库及迁移备份不作为测试夹具。
