# P6 临时答疑与删除契约

关联 WP-P6-001/002/003，REQ-004/024/025/029/036，T14/T15/T16。

2026-10-18 TURN-20261018-004：按已确认课程节点类型选择策略，不能由用户问题或模型自行切换。理论课允许通用知识、前置概念、推导和教学代码（包括#include、main、代码围栏），hint最多6000字符、expression最多2000字符；实验课保持提示型策略及原1600/160限制。两者继续校验JSON形状，仅显示文本，无工具、执行、修改或完成能力。格式拒绝不再误称问题越界。

## 答疑

TutoringSession 每个打开的课程窗口独占。只依赖计划读取、学习读取、材料读取、设置和 ModelEgress；不暴露文件写入/执行/完成接口。关窗、切课和重启均不恢复会话。只保存内存中的成功问答，失败/取消不追加，10轮后需显式清空；问题4000字符、主动代码16000字符。本课上下文限24000字符，截断标记显示在完整外发预览中。理论发送正文块而非答案字段；实验发送目标及说明，不扫描导出目录。答疑不能触发课程生成。

2026-10-18用户要求简化课内答疑：输入问题后点击发送即授权本次请求，不强制预览或二次确认。按钮旁告知发送范围，详情可选展开/收起。发送时重新Prepare固定当前模型、课程、对话、问题和主动代码快照，再通过既有ModelEgress派发；可选预览不作为发送前置条件。修改输入清除旧预览；清空或关窗使准备中的请求及迟到回复失效。Each/Once设置不增加课内答疑的操作步骤；其他功能授权不变。每次答疑至多一次请求，不自动重试；失败后明确重新发起。取消只能阻止接收，不能撤回已经派发的数据或费用。实际报告用量显示，不捏造费用。

实验课tutor-v1输出为JSON对象，严格两字段hint、expression。hint最多1600字符且禁止代码围栏/完整程序入口；expression为空或单行160字符以内，不含分号/花括号/预处理。提示词拒绝完整代写、执行和完成声明，模型输入不能授予这些能力。这是结构限制和教学提示，不能证明所有自然语言回复都遵守语义边界；真实模型负例与人工核验独立进行。UI以本地WPF富文本呈现导师Markdown常用子集（标题、强调、行内/围栏代码、列表、引用、分隔线），用户消息原文展示；不解析HTML/XAML，不加载图片或活动链接。代码仅可选择复制，不执行；不支持的语法保留文本。

ITutoringFiles仅接受宿主文件选择，单个UTF-8 .c/.h/.cpp/.hpp/.md/.txt；句柄校验、祖先目录固定、拒绝链接/别名，限64000字节及16000字符。不递归、不持久化路径、不自动外发；读取后仍可编辑/清除与拒绝。允许读取.cpp文本不代表已实现C++课程/材料生成。

## 删除与数据库

ISubjectLifecycle.DeleteAsync(subject,revision,confirmed)使用不含路径的学科UUID和当前修订；未确认、版本不一致均不删除。UI展示名称及范围并二次确认，默认“否”；执行前关闭当前学习窗口。固定数据根的planning.db及learning.db通过ATTACH加入同一个rollback-journal事务，要求DELETE journal和FULL同步。SQLite提交/回滚覆盖两个库，失败后重试不产生部分删除；不符合日志模式则拒绝操作。

清理drafts、成功请求缓存及planning outbox；learning全部该学科的正文/历史、attempts/mastery/completions/positions、generation及dispatches、lab packages/jobs/attestations、requests及outbox。保留共享知识、其他学科、外部源/导出/工作文件。没有文件递归删除。仅保留一个无内容UUID墓碑，写入路径在事务内检查，阻止已读取旧计划的并发请求重建数据；已删除任务的迟到回复拒绝。

learning.db v5新增deleted_subjects及requests.subject；v4响应缓存缺少可恢复的归属，升级时只失效此缓存，学习事实不变。应用不会跨重启重放旧命令ID。新命令归属明确；旧二进制拒绝写入v5，回退须使用升级前自备份数据与对应二进制。planning.db仍v1，冻结计划hash不重写。删除为业务数据清理，不追踪外部副本。
