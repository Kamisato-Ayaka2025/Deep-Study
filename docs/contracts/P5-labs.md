# P5 实验基础契约（禁用执行的开发范围）

状态：开发中；PSEC blocked；不是 P5 完整实现或验收。

- WP-P5-001：私有 LabDraft、无参考解 LabDraftPreview、材料校验与固定四课夹具。当前只处理内存数据，不调用模型、写实验工作区或登记 Runner 资源。
- WP-P5-002：后续持久材料/工具链指纹、参考解验证、Judge、稳定运行快照、首次全通过完成事务。依赖 PSEC 自动及人工签收，当前未实现。
- WP-P5-003：实验窗口、连续继承及恢复。当前只实现冻结计划预览与禁用控件；工作区、继承、恢复事务和真实反馈未实现。

`LabDraft` schemaVersion=1：说明、初始 C/H 文件、内部完整参考解、1–20 条 stdin/stdout 用例、连续项目 TODO 插入和来源键。它不是 Runner 请求，不能由模型字段授权执行。仅统一 CRLF/LF 的输出比较留给后续 Judge，不在材料校验阶段判分。

材料限制：相对正斜杠 C/H 文件名，拒绝设备名、ADS、穿越、大小写重名及文件/目录冲突；每组最多32文件，每文件65536字符、总262144字符。用例ID唯一，stdin/stdout可空但各不超过16384字符。来源必须同时属于冻结计划及实际传入来源。TODO须位于注释 token，字符串中的 TODO 不算；这不替代编译验证。补丁只能声明新文件或稳定锚点插入，禁止同批新文件再插入或重复锚点。是否覆盖继承文件、锚点唯一性和复制竞争须由未来工作区实现核验。

`fixtures/p5/continuous-four.json` 包含一堂独立起始实验及三堂连续实验，共四堂。合成累计器使用 header 中的静态函数，避免改变编译命令；参考材料与 TODO 分开。当前结构测试覆盖两种工具链身份，但没有编译/运行这些新夹具，不能称参考解验证通过或 T09–T13 通过。现有 Runner 资源白名单保持原样。

`LabExecutionBoundary` 为 fail-closed 常量策略，没有开关；前置满足仍禁用生成、参考解验证、开始、Judge、恢复。正常课程图实验节点打开 LabPreviewWindow，展示冻结方案与阻塞原因，不再误入理论生成页。无实验数据库迁移，无完成记录写入。

后续开放顺序：先解决 PSEC S1–S7 自动证据和 S8 人工签收；再接入真实生成、私有参考解验证、工作区和 Runner 登记协议，完成 T09–T13/T18 与双工具链门禁。不得删除 readiness 阻塞或使用 Fake Judge 交验。
