# P29 数据目录

用户决定：新安装默认放在程序旁data文件夹，同时提供更改目录选项。

解析顺序：当前启动配置的已保存选择 > STUDYHARNESS_DATA_ROOT > 程序旁已有data > 旧LocalAppData/StudyHarness已有库 > 程序旁新data。旧入口按原始数据路径分别保存选择，直接运行程序使用default.json；选择文件存于LocalAppData/StudyHarnessLocations，与数据库分离。

“迁移当前数据”选择独立可写空目录，保存待执行请求；当前会话仍使用原目录。退出托盘后重启，程序持有目标实例锁并确认原实例已退出，复制至临时目录，逐文件SHA256校验，修正复制后libraries.db中的内部库Root和缓存响应路径，再完成目录重命名与偏好提交。原目录不删除；意外退出后已完成复制可恢复偏好提交。未完成临时目录不作为学习库启动。

“切换已有数据”不复制或合并。目标缺失/非空冲突/原实例占用时拒绝继续，不静默创建空库；启动失败可撤销选择恢复原目录。设置中可取消尚未生效的选择。未保存密钥时先保存或放弃，遵守现有设置离开规则。

数据包括SQLite库、设置、日志和内部扫描缓存；WebView reader-profile缓存重新生成。外部独立资料库和原教材不搬动，冻结的来源身份及原教材路径不改。凭据只保证同一Windows用户下解密。目录须位于可写的普通本地磁盘文件夹；不自动复制链接。程序目录无写权限时需要放到可写目录运行。
