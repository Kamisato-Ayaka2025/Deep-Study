# P33 教学任务与资料组织开发/验收计划

范围：REQ-103 / WP-P33-001–003。实施用户所选1、2、3，不包含额外模型复核、局部修正按钮、反馈学习或新质量拒收。保持现有模型派发次数，复用原扫描/知识提取，不修改冻结计划和已有文章。

1. 每课生成时在宿主组织教学任务：学习者基础与目标、可观察学习产出指导、直接知识、必要前置、相关考题、示范/独立练习方向。不伪造已掌握状态、原题条件或薄弱点；未提取的细节由同一次生成进行教学设计，不额外模型调用。
2. 资料组织：每段保持原文及引用id，以文件/物理页/块和用途标识；直接证据、前置证据、相邻上下文分清。同页正文/图表保持完整，跨页证据按原有绑定保留。摘要明确是派生分析而非原文，模型补充与原题区分。无绑定的历史资料保持兼容。
3. 讲解指导：问题—原理—完整示范—改变一个条件—独立练习，按概念/推导/计算课灵活选用，不强制五节标题。示范解释为何这样做，练习检验迁移而非照抄。试卷用于题型/难度参照，不按单卷频次预测考试范围；教材基础不因未考删除。独立quiz仍只有题目及答后参考答案，不注入讲解模板。

验收：离线测试检查任务内容/来源角色/同页跨页原文保留及旧计划兼容；端到端模拟提供者核验请求并发布正文，确认没有额外派发；真实WPF/WebView及独立重启验证；全回归、Release与候选包校验。真实模型教学质量留人工核对，离线样例不宣称真实API内容质量。本轮不调用收费模型/OCR，不写真实用户库。候选1.14.0-rc.2。
