## 2. 选择的路线与对照方案

主路线：本地持久化完整取得的资料 → 页/章节/主题分块 → 全局目录及可追溯分层摘要 → 本地全文检索与章节邻接扩展 → 按任务装配较长但有界上下文 → 模型生成 → 确定性规格校验 → 原子发布。

计划使用全局章节/主题目录、各章节覆盖摘要和目标相关原文，避免只看命中的少数段落导致漏章；单课使用冻结计划、本课目标、关键定义/推导/例子原文及必要前置，不反复发送整本。摘要绑定具体源块，源块不被摘要覆盖。来源不足明确补取或报缺口。

先用SQLite全文索引配合中文切分/字符n-gram、章节路径、目标词和邻接页；基准验证同义词、跨章及中文检索漏召回。向量检索不作为新增云服务依赖，只有实测显示关键词方案不足时另作ADR比较本地向量索引的效果、包体与速度。长上下文整本直传仅作为有界对照实验：上下文装得下不证明吞吐、成本或教学覆盖达标，不能据此直接选择全量直传。

使用现有DeepSeek提供商。官方[模型元数据接口](https://api-docs.deepseek.com/zh-cn/api/list-models/)定义context_window与max_output_tokens，并给出deepseek-flash约1M上下文的示例；这是文档能力说明，不是本机吞吐或账号实测。实施时读取当前模型能力并缓存时间，未知值采用保守配置并告知；不硬编码示例为所有模型能力。

OI Wiki的[官方目录](https://oi-wiki.org/)和[FAQ/仓库入口](https://oi-wiki.org/intro/faq/)可用于目录发现和版本化来源设计。正文获取沿用获准服务端Fetch边界；下载仓库快照是候选优化，须先记录新目的地、授权、内容许可及安全边界，不自行把Git/构建脚本变为产品依赖，不执行仓库内容。无法穷尽发现的页面不能声称“全站完整”。

自动分类输出为有版本结构：domain（主题描述）、teachingModes（theory/exercise/project组合）、reason、materialCapabilities、limitations/clarifications；这些是设计字段，不是现有API。宿主白名单验证能力及依赖，不用固定学科关键词代替LLM选择。数学证明/纸笔练习可走通用文本任务；网络项目可交付具体外部操作和观察要求；新增源文件能力必须独立审查Schema及安全规格，不扩大旧C校验器。

## 4. OCR与资料处理

先全页清点文本层/图像和目录；有可用文字层的页不重复OCR。图像页按批次渲染、必要缩放后发至已配置且支持视觉的DeepSeek；缓存键绑定文件hash、页号、图像处理版本和识别模型/提示版本。页结果包含文本、原页定位、识别质量/未解读区域；公式/图表不自动认定正确，课程引用可回到页定位。

先以少量代表页验证中文、公式、表格、图示和耗时，再估计全书请求/用量；费用无法可靠估算时说明未知，不编造精确金额。用户界面明确将发送哪些页图像，尊重已有一次/逐次授权选择；本轮允许路线不等于已外发这本教材。任何已授权批次变更范围重新确认。原始PDF整本上传不作为默认路径。

建议起始资源档：文件上限512 MiB、最多2000页，单页处理和缓存落盘，避免整书多份byte[]；具体并发、图像像素/字节、提取字数和磁盘上限先测量再冻结。上限提升不能删除路径/硬链接/重解析点保护；OCR取消需中止后续派发，已完成页事务保存。重启仅显示可继续，不自行收费续传。图像或文本解析失败列明页码，不能以空页完成覆盖。

OI集合以全站目录组织知识，保存发现清单、成功正文、失败原因和未取状态；目录覆盖不等于正文已读，按目标/课程需要获取正文，不等待全站正文下载。计划确认时绑定不可变集合清单版本。按需取得的正文绑定该版本实际内容，不能用后来变化的页面静默替换。共享索引保留，删除课程只删拥有的引用/任务，沿用P6事务边界。

## 5. 预算、时延与失败语义

工作流预算统一约束：inputTokens + outputReserve + safetyMargin ≤ 模型contextWindow；每次输出≤模型maxOutputTokens；聚合所有工具消息及多阶段请求用量。字符数仅是提前拒绝的保守估算，不冒称精确token。检查现有200000用量校验等旧常量是否不再适用。

先测代表性请求的首字时间、完整生成时间、输入规模/输出速率，再定计划与长课预算。输出长度优先由教学目标与深度确定；若预算不足，在确认前调整拆课/范围，不能生成后悄悄缩水。可选分节生成只作路线备选，先更新“逻辑任务/子请求/总重试上限”的契约，不能把既有3次派发限制按每节重新计数。内容校验失败不伪装临时网络错误重试。

计划目标600秒，单课目标300秒；首次OCR/资料准备单独计时，不计入计划目标。准备完成进入计划生成阶段为计划计时起点；单课以用户触发为起点，终点均为完整可用产物校验后发布。生成阶段按需取材、模型往返、重试和校验均计入，不能挪到首次准备阶段；同时报告总等待时间。单课学习时长由LLM按目标/周投入安排，无统一时长区间；课文应充实而非凑字。超时保留旧内容及检查点，给出当前状态/取消；后台迟到结果必须经过任务身份与取消检查。

不要求为了更长课文无条件提高全部长度上限：先对齐Schema、解析器、UI、保存、模型响应体和预算，再通过深度/完整性样例。最少一题完整测验保持；代码和项目仍只交付材料。

## 6. 基准与交付证据

三组固定基准：A指定扫描网络教材（全页清点+代表性章节OCR质量）；B数十万字可提取文本（前中后章/跨章目标）；C固定版本OI Wiki集合（目录与正文覆盖清单）。另回归无资料入口和V1 C/C++/数学课程。不得提交真实教材或学习数据库；证据仅保存脱敏大小/hash、范围、时间、用量、缺口及检查结果。

每组至少一次冷路径与一次缓存路径，代表性主题至少三堂不同位置/复杂度课程；另用合成夹具覆盖失败/超限/取消。小样本报告每次值和最大值，不声称统计p95。首次预处理时间、模型时间、整体时间分别保存，失败与超目标不得剔除。收费验证在实施轮核对授权范围后进行，本轮未运行。

质量门槛：目标与章节覆盖无静默遗漏、引用可回原文、关键定义/推导前提正确、至少一个实质例子、至少一题完整且答案可核验；通用项目含明确操作/输入/预期。真实内容人工复核与程序规格测试分列。用户最终验收后才关闭P8。

## 7. 冻结工程契约 v1（TURN-20261019-006）

冻结日期2026-10-19。以下是实现边界而非已交付声明；修改须补版本、测试及TURN。证据见[基线](../assessment/P8-baseline-20261019.md)。小样本不替代005/007端到端质量与冷/热门禁。

### 7.1 能力与预算

- ModelCapabilities v1见Contracts：model、contextWindow、maxOutputTokens、supportsImages、observedAt、verified。固定GET https://api.deepseek.com/models，无正文/页图，禁重定向，30秒/64KiB响应；精确匹配模型。缓存24小时，换模型/过期/未知能力降到32768上下文、4096输出、禁图像；界面说明能力待刷新。不从模型名推断视觉。
- 实测deepseek-flash：1048576上下文、393216输出上限、image输入；这是2026-10-19账号快照，不硬编码为通用值。普通6样本11.38–14.36秒；长输出2样本39.51/40.01秒，8180/8718输出tokens，未截断。
- 新路径单次输出预留16384 tokens；未知能力4096；始终取服务能力上限较小值。完整序列化提示/工具历史的UTF-8字节数作保守输入准入估计，不是精确tokens，最多393216字节；另留8192安全余量，合计不得越contextWindow。图像预算独立，不把base64长度当文本tokens。
- 单次响应4MiB，理论正文65536字符、最多128块、单块16384字符、1–20题完整测验；解析/存储/Schema/UI全部对齐后才启用。正文目标由教学目标决定，字数不作质量证明。计划最多240节点、节点预计分钟为正整数且≤10080，周投入≤10080分钟；超限须在确认前明确缩小范围或拆分，不能遗漏目标。
- 一个逻辑计划/单课任务所有模型子调用最多3次派发，其中最多2次临时错误重试；取材改为宿主先装配，禁止每节重置计数。本版不采用分节生成。实际发出即消耗额度；内容校验失败不重试。用户显式再次发起为新任务，保留历史失败/用量。
- 目标600秒计划/300秒单课；硬停止900/600秒，包含生成阶段取材、重试和校验。达到目标提示延迟且可取消；超目标样本保留，验收须优化或用户接受例外。CancellationToken绑定IO，旧revision/取消任务的迟到结果不得发布。

### 7.2 输入、策略和实践

- 小时输入(0,168]，接受能精确表示整数分钟的decimal，绝不舍入。建议步进0.1小时；0.05小时=3分钟合法，0.01小时不合法。旧1分钟等循环小数显示“0小时1分钟（原值1分钟）”，不回写原分钟/hash。Domain WeeklyStudyTime统一转换。
- StrategyDecision v1及strategy-decision.schema.json：domain自由主题描述；teachingModes仅theory/exercise/project；reason非空；materialCapabilities仅paper-exercise/manual-project/portable-c/portable-cpp；limitations/clarifications数组。模型选择，宿主验证，用户无类型控件。
- 策略须与节点/能力一致：无实践时能力为空；paper-exercise依赖exercise；manual-project依赖project；portable-c/cpp须实践节点。未知/缺依赖拒绝。CppAlgorithms继续逐算法理论+题目覆盖，不用通用材料规避。
- 新PlanCandidate schemaVersion=2增加strategy、coverage；旧schemaVersion=1及scope/分钟原始序列化保持，不重算hash。新scope固定Adaptive，自然语言request承载用户修正。v2 coverage逐目录项标included（节点键）/excluded（理由）/unavailable（缺口），目录不作正文引用。
- 新通用材料schemaVersion=5：kind=exercise/project，capability=paper-exercise/manual-project，title、objectives、prerequisites、tasks、assessment、sources；tasks各含id、action、input、expectedObservation、acceptance。练习须有答案/推导评判点，项目须明确操作和预期。只导出宿主生成README.md，不接收模型任意文件名、脚本。C schema3/C++ schema4校验器保持独立。

### 7.3 来源、OCR、缓存与覆盖

- SourceCollection固定id、sourceKind(pdf/text/site)、sourceFingerprint、createdAt。CoverageManifest v1绑定目录hash/版本；Entries含key/locator/heading/state/contentHash/failure/qualityFlags；state仅discovered/textReady/ocrReady/failed/unavailable。DirectoryComplete仅表示指定目录清单完整，不等于全站正文已读。
- PDF文件页序从1开始，印刷页码仅辅助。块绑定collection/version/entry/contentHash/字符区间；摘要另表并列父块hash，不冒充原文。块目标2000–6000字符、上限16000字符，全文保留，章节及邻接扩展检索。中文bigram/拉丁词SQLite FTS5；索引命中不等于已读取。
- OI目录使用官方sitemap+导航页，存hash/时间/发现URL；本次465个sitemap地址和463个首页同站链接不强行等同。最多10000条、目录响应2MiB；正文沿用服务端Fetch，保留真实返回元数据，不虚构最终URL。变更正文形成新版本，不覆盖已确认快照。无需全站正文预下载。
- 010实现细化：目录键以d1/entry等紧凑别名映射到PlanDocument.Collections冻结顺序，全部映射纳入计划hash。OI发现项可规划为included并标fetchOnDemand，表示课程范围，不表示正文已读；按课首次成功正文作为该目录版本不可变回执，后续刷新需新集合版本。扫描未识别页无此标记，不能假装已覆盖。固定目录GET无凭据、禁重定向、直连公共IP；正文仍仅走服务端Fetch。summaries是绑定父块hash的提取式索引预览，不声称语义摘要完整。
- PDF≤512MiB/2000页，只读受保护句柄流式hash/分页，保留重解析点/硬链接/范围保护。开发脚本不代替安全导入。单页长边2000像素、总像素≤4百万、PNG≤4MiB、并发1；不可辨认时明确需重选范围，不无界放大。单集合缓存硬预算2GiB；图像批次临时文件用后可清理，OCR正文/定位持久保存。
- OCR每页1个正常请求，临时错误最多2次重试；每授权批次≤20页，总派发≤页数×3。全书分明确页范围批次；重启仅提示续作，不自动续费。资料准备每页上限不得用于扩大生成任务3次上限。
- OCR缓存键=文件hash+页序+渲染版本+模型+prompt版本；保存正文、状态、usage、qualityFlags。所有OCR默认unverified；含图/公式标visualReviewRequired，缺字/截断/缺图显式标记。实测存在标签遗漏，不能以传输成功取消标记。失败页不计覆盖。
- 外发授权绑定模型/目的地/页范围/图像hash/识别版本/预计批次。本轮五页授权不扩大至全书；新页外发先确认。只发送批准页图，不传PDF/目录/数据库；费用未知不编造金额。
