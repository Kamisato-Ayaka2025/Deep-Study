# Deep Study 1.10.0

Windows 本地学习应用：从教材建立课程，阅读理论与测验，生成实验材料并由学习者在外部自行测评。课程、进度与扫描缓存保存在本地；远端识别和内容生成需要用户配置并授权服务商调用。

## 运行

Windows 10/11 x64，.NET 10 Desktop Runtime 和 WebView2 Runtime。解压完整程序包，在同一目录运行 StudyHarness.Desktop.exe。PPT/PPTX 图形渲染需要本机 Microsoft PowerPoint；无需为学习实验安装本地编译器。

默认数据目录是 `%LOCALAPPDATA%\StudyHarness`；设置了 `STUDYHARNESS_DATA_ROOT` 的自定义启动方式继续使用指定目录。请一直使用相同的 Windows 账户与原启动方式；凭据受 Windows 当前账户保护。程序包不包含课程、资料或密钥。

## 从 1.6.0 或 1.6.2 升级

下载 Release 中的升级包，将它解压到独立目录。先从托盘完全退出 Deep Study，双击 `upgrade.cmd`，输入旧 `StudyHarness.Desktop.exe` 所在的程序文件夹（不要选择数据目录）。升级器校验包文件，只替换程序文件；数据库、教材、缓存、启动脚本与其他文件不删除、不移动、不覆盖。程序文件备份保留在旧目录 `.deepstudy-upgrade-backups` 下。

升级后继续使用原快捷方式或启动脚本。默认数据位置不变；自定义 `STUDYHARNESS_DATA_ROOT` 也不变。升级器不会自动启动应用。首次打开如需要升级存储结构，由程序原有备份/迁移流程处理。升级前仍可自行备份数据目录；不要用空目录替换原目录，也不要把数据上传到 GitHub。

如复制新版完整包到新目录，也可直接运行以继续默认数据；使用自定义数据目录的用户须保留原环境变量/启动脚本。单纯换了数据目录会显示空库，并不表示原数据已删除。

## 本版更新

- PDF 自动扫描支持八并发；PPT 扫描流水处理与缓存续扫。
- 多资料连续导入队列、分页教材均衡取样和计划正文预算改进。
- 可选本地声明式课堂图示；不自动联网搜图，不执行模型脚本。
- 长课文与课程目录增量复用，轻量界面反馈和连续滚轮平滑处理。
- 独立课程窗口及托盘生命周期；关闭窗口可在托盘继续，退出请使用托盘菜单。

导入待处理队列只在本次运行保存，已扫描结果持久保存。模型内容仍需核对。学习实验只生成/导出材料，不在应用内编译或运行生成代码。

## 源码构建

运行 `scripts/bootstrap.ps1` 安装固定 SDK，之后先 dot-source `scripts/environment.ps1` 再执行 `dotnet build StudyHarness.slnx -c Release`。公开仓库只含产品源码和合成测试，不包含私人开发历史或用户资料。
